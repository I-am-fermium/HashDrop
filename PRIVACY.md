# Privacy and Permanence

## Public by default

Solana on-chain data should be treated as public and permanent.

Users must be warned before publication that other parties may copy published content and that deleting a website or temporary copy does not erase downloaded copies.

## Product rules

Do not describe HashDrop as private storage.

Do not encourage the publication of:

- passwords
- private keys
- seed phrases
- API secrets
- personal confidential data
- proprietary material the user does not intend to make public

## No legal ownership claim

HashDrop provides cryptographic publication and provenance. It does not by itself establish legal copyright ownership.

## Canonical data

The canonical ON-CHAIN record must not depend on a centralized content database.

Temporary client/server transport, if ever introduced, must not become the canonical record.
